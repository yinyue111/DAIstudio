# 图片/视频提示词反推完整实施计划

> 状态基线：2026-07-17 当前工作树。本文档是功能完成度和验收基线，不按“一期”裁剪。

## 1. 目标工作流

`URL/上传/资产 -> 主素材与参考角色 -> 目标/精度/用途/费用 -> 证据化反推 -> 待审阅结果 -> 选择性应用 -> 模型适配 -> 生成 -> 源/生成复刻度评估 -> 修正版本/局部重生成 -> 版本/配方/质量闭环`

提示词优化保留在 Studio 编辑器内，以对比建议形式接受或拒绝，不新增顶层 Tab。

## 4. 全局验收条件

- 任何反推结果都不会静默覆盖工作区。
- 可以从任务、版本或创作配方恢复完整参数并继续生成。
- 视频动作、运镜、OCR 和音频结论能定位证据；无证据时明确降级。
- 图片的文字、Logo/包装、保护项和可变项可结构化审阅。
- 切换目标生成模型时可重新编译提示词，不重新调用视觉反推。
- 管理端能按模型、反推目标和媒体类型查看成功、费用、证据、采用和生成转化数据。
- 图片和视频生成后可与源素材分维度对比，问题能定位到区域或镜头，并通过新修正版本继续生成而不覆盖历史。
